# OmniTask

OmniTask is a backend task management system built using Python.  
It provides APIs for user authentication and task management.

---

## Features
- User authentication
- Create, update, and delete tasks
- Database persistence using SQLite

---

## Tech Stack
- Python
- FastAPI
- SQLite
- SQLAlchemy
